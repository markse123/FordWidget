Complete usage guide ↗
Can I choose a different widget design?+

Open Widget gallery to preview Classic, Showcase or Dashboard using saved readings, then apply a design separately to each Home Screen size. Classic is the default. The classic, showcase and dashboard Parameters override the design for one widget. Pro Power fields remain optional.

What are Alerts & attention?+

Choose evening alert conditions and tire, fuel, oil and 12V battery thresholds. The optional Home Screen attention indicator shows the first matching cached condition and its age without another cloud read. Missing readings remain unknown, and old data can produce an old warning. iOS controls refresh and notification timing.

How do I check vehicle compatibility?+

Vehicle features / compatibility checks the script offline, suggests readings from cloud or saved data and lets you choose available features. Connect FordPass and rerun it after Fetch telemetry for cloud suggestions. Missing data is unverified, not proof of incompatibility. Optional command tests send real commands after confirmation and record your completion report. Other Ford models remain unverified; electric vehicles are outside the current testing scope.

How does Refresh work?+

Refresh opens Scriptable and asks “Refresh all widget data?”. After confirmation it requests general vehicle and Pro Power status, then reads the available cloud data. It respects cooldowns and can take around a minute. A successful request does not guarantee every measurement changed. iOS controls when the Home Screen widget redraws.

For Pro Power alone, use Pro Power → Request status once…. For a cloud read without a vehicle-status request, use Fetch telemetry or Read cached Pro Power. Cached reads still contact Ford’s cloud.

Why is outside temperature unchanged after Refresh?+

A completed request does not prove the temperature measurement changed. After a successful combined Refresh, open Troubleshooting → Vehicle data report → Copy report in Scriptable. The temperature section compares Ford's raw reading and timestamps with the saved value and hypothetical parse/merge result. It collects evidence without a vehicle command or a telemetry update. See the temperature capture instructions.

Can I switch the outlets on and off?+

Use the truck’s controls for outlets and Generator Mode. This fork adds Pro Power monitoring and status requests. The retained Start/Stop buttons control the engine through their existing confirmations; Refresh does not start the engine or switch outlets.

Which Pro Power systems have been tested?+

Monitoring has been tested on one US 7.2 kW F-150 PowerBoost, including A and B under load together. Circuit A was compared at two loads. Separate circuit B accuracy, physical outlet mapping, other power ratings and Canada remain unverified. A/B labels refer to reported circuits.

Will I keep the original widget features?+

Yes. Fuel/range, battery, tires, oil, locks, doors/hood, odometer, temperature, location, photos, controls, notifications and the original widget sizes remain available. Pro Power fields are optional. A named Parameter selects only those fields; leave it blank to follow Customize widgets.

Where do my Ford details go?+

This installation page has no Ford sign-in form, vehicle telemetry or analytics. Ford sign-in and vehicle requests happen in Scriptable. Tokens use Scriptable’s shared Keychain, which other installed scripts can access. Only install scripts you trust. See the privacy notes for local cache, location and weather behavior.
