LET’S GET YOU SET UP

Three steps. One widget.

Open this page on your iPhone and follow along.

01 — 03
01 / GET THE APP

Install Scriptable

FordWidget runs in Scriptable, a free app for iPhone. Download it from the App Store.

Download Scriptable ↗
02 / COPY THE INSTALLER

Copy the installer

Copy the small installer. It downloads FordWidget from the project’s compatibility branch when you run it.

Show installer code

You can select and copy this code manually if your browser blocks clipboard access.

03 / FINISH IN SCRIPTABLE

Install FordWidget

Open Scriptable, paste the installer into a new script, then tap the ▶ run button. Choose your storage and follow the prompts.

Open Scriptable ↗

After installation, return to your script list and run FordWidget to connect your vehicle.

✓
Next, add your widget.

Touch and hold your Home Screen, add a Scriptable widget, then select FordWidget in its settings. See the full guide ↗
